# Archive

This directory indexes historical design, evidence, and pressure-test material that remains useful but is not current authority.

Do not move immutable official material here.

Use these indexes before opening historical files:

- `docs/archive/evidence-era-map.md`: which older evidence belongs to which architecture era.
- `docs/archive/progress-history-map.md`: how to read archived `docs/archive/progress/p*-progress.md` files and `docs/archive/progress/p3-decision-log.md`.
- `docs/reviews/README.md`: how to read historical review files.
- `docs/perf/pts/l4b-kafka/report-review-index.md`: how to read historical/current-adjacent PTS report reviews.
