## 0. 一句话结论（调研层面）

- **标杆不是“更花哨”，而是“更克制、更可信”**：Whatnot / 苏富比 / 佳士得 / 抖店竞拍工具的共性是——把“倒计时 + 当前价 + 下一口价 + 一个出价主按钮”做到极致清晰，把其余信息折叠进半屏/抽屉；用**等宽数字**和**服务端权威状态**传递“工程可信”。
- **一条贯穿全局的合规事实**：抖音直播间内的工具是 **“竞拍 / 网络竞价”，不是有牌照的“拍卖”**。平台强制卖家**回避一切“拍卖”字样**（用“竞拍/开拍/出一手/中拍”），且消费者 **7 天无理由退货仍然适用**。这直接决定了文案、免责声明和结果仪式的措辞。来源：[抖店竞拍工具手册](https://school.jinritemai.com/doudian/wap/article/aHVWVc8vGCWh)、[云南拍卖协会法务问答](http://www.ynpmxh.com/h-nd-3487.html)。

## 一、C 端：直播竞拍买家体验

### 1.1 出价面板的“黄金顺序”（实证）
Whatnot（移动优先、节奏最快）公开口径：倒计时**常驻**；当前最高价 / 参拍人数 / 出价数实时更新；**出价前永远先显示“下一口有效价”**；主按钮是**一个大“Bid”按钮**（移动端**滑动确认**）；**运费写在标题下、出价前可见**；旁边有“Custom/自定义/设置最高价（Max Bid）”。苏富比/佳士得在线台同构：当前价、每件**独立倒计时**、Place bid + Quick Bid（下一档）+ Max Bid。RM 苏富比还显示**自己的名次 1–5，第 6 及以后显示“5+”**。

→ H5 出价面板优先级（高→低）：**倒计时（最大，末段变色）→ 当前价 → 我的状态（领先/被超过）→ 下一口价（写在按钮里）→ 出价主按钮（拇指区、滑动/长按确认）→ 自定义/最高价 → 上下文（出价数/参拍数/含运费/保证金状态）**。
来源：[Whatnot 出价](https://help.whatnot.com/hc/en-us/articles/14932924544141-Bid-on-an-item-during-a-show)、[苏富比 Buy&Sell](https://www.sothebys.com/en/buy-sell)、[RM 苏富比](https://rmsothebys.com/questions-about)。

### 1.2 “下一口价”与防误触（最一致的铁律）
- **永远不要让买家自己算下一口价**。Whatnot：“出价前永远显示下一口有效价”，滑动即出该价。
- 抖店：**固定加价**（支持 2 位小数）+ 可选**封顶价**（出价≥封顶→自动结拍按封顶成交）；**起拍价为整数，允许 0 元起拍**（“捡漏”钩子）。
- 淘宝/阿里拍卖出价合法性规则：①首次只能出起拍价；②只能按加价幅度的整数倍出价；③**领先者在仍领先时不能再次出价**（防自抬）；④出价时账户无需冻结资金。
- 佳士得有公开**加价阶梯表**（如 $100–2000 档 +$100，$1万–2万档 +$1000……），经验法则约为上一口价的 **≈10%**。
- 防误触：苏富比 **Quick Bid 需“按住并把按钮滑到最右”确认**；Whatnot **滑动出价**、自定义大额时 **Max Bid 默认开启**（代理出价而非一次性巨额）；并有“明显误操作可取消重拍”的兜底。
来源：[Whatnot](https://help.whatnot.com/hc/en-us/articles/14932924544141-Bid-on-an-item-during-a-show)、[抖店手册](https://school.jinritemai.com/doudian/wap/article/aHVWVc8vGCWh)、[淘宝拍卖帮助](https://www.taobao.com/markets/paimai/sf-helpcenter)、[佳士得财务信息](https://www.christies.com/en/help/buying-guide-important-information/financial-information)、[苏富比](https://www.sothebys.com/en/buy-sell)。

### 1.3 倒计时 + 软关闭/延时（“防最后一秒抢拍”且不显得做局）
- **快节奏直播（最贴近本项目）**：Whatnot 双时钟——标准计时（每次新出价**加几秒**）+ **反超计时（剩余<10 秒时每次出价把计时重置）**；**Sudden Death** 不延时、到 00:01 即成交，并在计时旁显示 **💀 图标**标明玩法。抖店：竞拍时长 30s/1/3/5/10 分钟；**延时 0/10/15/30 秒（默认 10s）**；“即将结束时有人出价成功则自动延长”。
- **慢节奏（仅供文案/时长参考）**：淘宝**延时周期 5 分钟**，且帮助页**专门辟谣**“无人出价不会提前结束”；苏富比“最后 1 分钟内出价则延长 2 分钟，最多 2 小时”；佳士得“最后 3 分钟内出价则再延 3 分钟，直到 3 分钟无出价”，且**可能不按编号顺序结拍**。
- **买家认知证据**：Reddit 上反复有人问“最后加 5 秒是不是骗局”，社区共识是**软关闭是公平机制**——同一机制**贴上原因标签**就从“做局”变“公平”。
- **诚实制造紧张的中文文案**：延时时“**有人出价，延时 +10 秒**”“**延时中…再战一手**”（先说原因再邀请）；末段“**还剩 3 秒**”变色放大；不延时玩法用“**不延时 · 截止即成交**”徽标。
来源：[Whatnot 出价](https://help.whatnot.com/hc/en-us/articles/14932924544141-Bid-on-an-item-during-a-show)、[Whatnot 开拍](https://help.whatnot.com/hc/en-us/articles/9779931101837-Start-an-auction-during-a-show)、[抖店手册](https://school.jinritemai.com/doudian/wap/article/aHVWVc8vGCWh)、[淘宝拍卖](https://www.taobao.com/markets/paimai/sf-helpcenter)、[苏富比](https://www.sothebys.com/en/buy-sell)、[佳士得 FAQ](https://www.christies.com/en/help/frequently-asked-questions)、[Reddit r/whatnotapp](https://www.reddit.com/r/whatnotapp/comments/1n29suy/is_it_normal_to_see_an_auction_thats_about_to_end)。

### 1.4 领先 / 被超越的情绪反馈（与“服务端权威/失败兜底”直接对应）
- Whatnot：最高出价者旁显示 **“Winning”**；被超越触发**推送**邀请再出价。苏富比：被超越**邮件通知**并在“My Bids”改状态。RM 苏富比：以**名次变化**表示被超越。
- **重大反面教材（必须避免）**：Invaluable 应用商店差评——APP **声称“high bidder”但实际并非**，无被超越通知、过期“领先”状态一直挂到结束，最后输给“相同出价但更早”的人。这正是“客户端乐观成功 + 未告知平局规则”的最坏组合。平局规则本身是标准：**相同金额，先出者优先**（佳士得 / Whatnot 同口径）。
- → H5 应：**领先**=常驻绿色“您当前领先 ¥X”+轻正向反馈；**被超过**=立即红/琥珀“已被超过，需 ¥X 反超”+一键反超（预填下一口）+更强反馈；**严格区分“您的出价无效/未被接受（拒绝）”与“被他人超过（有效）”**；**重连/不确定时一律 fail closed 到“状态确认中”，绝不显示过期“领先”**。
来源：[Whatnot 预出价](https://help.whatnot.com/hc/en-us/articles/14933026908301-Pre-bid-on-an-item-before-a-show)、[苏富比买家指南](https://help.sothebys.com/en/support/solutions/articles/44002518078-guide-for-buyers-global)、[RM 苏富比](https://rmsothebys.com/questions-about)、[Invaluable 差评](https://apps.apple.com/us/app/invaluable-auctions-bid-live/id944415329?see-all=reviews)、[佳士得注册与出价](https://www.christies.com/en/help/buying-guide/register-and-bid)。

### 1.5 榜单/名次：两种哲学，珠宝场景该选哪种
- **市场/社交型（Whatnot）**：**无公开买家榜**，Max Bid 私有，所有人只看“当前最高价 + 出价数”。好处：隐私 + 抑制攀比/减少“托儿”嫌疑。
- **拍行型（RM 苏富比 / Invaluable）**：给买家看**自己的名次（1–5 / 5+）**，但买家彼此匿名。
- **中国直播现实**：榜单能量来自**弹幕 + 出价滚动流**（“X 刚出价 ¥Y”），不是实名榜。
- → H5 建议：**匿名出价流 + 自己的私有名次**（“您当前第 1/第 3”），不做实名公开榜——既保留紧张/社会证明，又降低“托儿”观感与隐私风险。
来源：[Whatnot](https://help.whatnot.com/hc/en-us/articles/14932924544141-Bid-on-an-item-during-a-show)、[RM 苏富比](https://rmsothebys.com/questions-about)、[抖店手册](https://school.jinritemai.com/doudian/wap/article/aHVWVc8vGCWh)。

### 1.6 保证金与信任（最易翻车，证据最硬）
- **保证金机制**：抖店**全场保证金**（一场一次，解锁全场带保证金商品）；罚没口径精确——**罚没 = min(保证金额, 中拍未支付订单额之和 × 30%)**，多退少补；未中拍或已结清则退。得物：**出价交保证金 + 自动跟价 + 30 天自动撤销 + 新卖家首单≤50 次**，并以集中**查验/鉴别**兜底。淘宝/京东：报名交保证金→生成**竞买号**；按钮随状态从**报名/交保证金→等待开拍→出价**演进；京东主推**三大保障 + 保证金抵货款**。
- **“无托儿/反自抬”必须可见**：Whatnot 明确**禁止 shill bidding 并告知买家**，且**“你出价，你就买（binding bid）”**；抖店禁止刷单自抬、可拉黑“只拍不付”。
- **证书/品相信任危机（央视/新华/新京报实锤，trust UX 必须主动防御）**：珠宝鉴定证书低至 **¥1.2 代做**、可**盗用真机构编号**；合规命名应为 **翡翠（A 货）/翡翠（处理）**，违规话术如“天然翡翠/玻璃种”；可经 **CMA / 市场监管总局** 平台核验。还有**套证/掉包**（真证书配假货）、**美颜灯光**导致“货不对板”。微拍堂曾被**央视曝光售假、罚款 ¥135 万**；对庄翡翠以**第三方鉴定担保 + GID 实验室 + 终身复检**立信。
- → H5 信任 UX：内联**可核验证书（机构 + 编号 + 官方查询深链）**，按**法定命名**标注处理状态；突出**店铺资质/保证金额度/发货地**；强制**“竞拍非拍卖 · 支持 7 天无理由”**披露；“假一赔 X”要有背书；保留**防篡改回放/出价记录**（骗局房常删回放对抗维权——这与本项目“可回放恢复/审计”要求天然契合）。
来源：[抖店手册](https://school.jinritemai.com/doudian/wap/article/aHVWVc8vGCWh)、[得物 FAQ](https://fast.poizon.com/poizon/detail/zh_MO/MO/67053117fd0122250e149ca6)、[淘宝拍卖](https://www.taobao.com/markets/paimai/sf-helpcenter)、[京东拍卖](https://zcpm.jd.com)、[Whatnot 社区准则](https://help.whatnot.com/hc/en-us/articles/360061197472-Whatnot-Community-Guidelines)、[新华网·玉石直播陷阱](http://www.news.cn/fashion/20250423/9834d19741274c148aef99bb929d9dae/c.html)、[新京报·珠宝直播调查](https://m.bjnews.com.cn/detail/164739734014419.html)、[对庄翡翠](https://www.duizhuang.com)、[36 氪·微拍堂](https://m.36kr.com/p/1759098143859719)。

### 1.7 结果仪式：落槌 / 成交 / 流拍（含合规话术）
- **权威术语**（苏富比中文）：**落锤价（Hammer Price）/ 击槌（Knocked Down）/ 成交 / 流拍（未达底价）**。
- **抖音强制非拍卖话术**：用**竞拍/竞价**；开始用**开拍/开始竞拍**（非“开始拍卖”）；邀约用**点击出价/加一手/顶一手/出手**；中标用**中拍/竞拍成功/成功竞得 XX**（非“拍卖成功”）。
- **赢家流**：Whatnot 到点自动用绑定支付方式成交，bid 即买；抖店赢家须在**竞拍支付时间**内支付否则关单 + 触发保证金罚没。
- → H5 仪式：**赢家**=全屏“落槌！恭喜竞得 ¥X”+ 限时支付卡（含运费/税、保证金抵扣说明）；**输家**=克制挽留“本场惜败 ¥X 成交”+ 下一件/关注开播/同款求购；**流拍**=“无人出价/未达起拍”+ 再拍一次；**赢家/落槌严格以结算侧确认渲染，绝不以客户端倒计时归零为准**。
来源：[苏富比拍卖术语](https://www.sothebys.com/zh-hans/拍卖术语)、[抖店手册](https://school.jinritemai.com/doudian/wap/article/aHVWVc8vGCWh)、[Whatnot](https://help.whatnot.com/hc/en-us/articles/14932924544141-Bid-on-an-item-during-a-show)。

### 1.8 直播间外壳 IA（视频 + 商品 + 出价 + 弹幕如何不挤）
- **全屏竖屏视频为底**；弹幕/商品为**叠层或右推面板**，不另开页；宽屏/折叠屏惯例是**把视频推左、右侧露出评论**而非遮挡。
- **拇指区**：主 CTA（出价/购买/支付）放**下 40–50%**，用**吸底栏**常驻；次级（分享/收藏/关注）放更高且不抢位。**触控目标 ≥48px，正文 ≥16px**。
- **底部半屏（Bottom Sheet）**：适合**临时的出价/商品面板**，但 NN/g 警告——**不要把半屏当常驻页**、**不要堆叠多层半屏**、必须有**关闭按钮**、支持**返回即关**。直播间本体必须是稳定的“家”。
- → H5 外壳：全屏视频 + 左下弹幕 + 右侧竖排动作栏（关注/点赞/分享/商品袋/保证金状态）；**出价面板=活跃拍品时的常驻吸底栏**（倒计时 + 当前价 + 下一口价 + 滑动出价），可展开为半屏看自定义/最高价/出价历史；**商品列表=抽屉（商品袋）**列“预展/竞拍中/已结束”；证书/品相详情下沉到拍品半屏，**外壳常驻只留“倒计时 + 价 + CTA”**。
来源：[NN/g 底部半屏](https://www.nngroup.com/articles/bottom-sheet)、[拇指区 Parachute](https://parachutedesign.ca/blog/thumb-zone-ux)、[Smashing 拇指区](https://www.smashingmagazine.com/2016/09/the-thumb-zone-designing-for-mobile-users)、[移动电商 UX](https://www.digitalapplied.com/blog/mobile-commerce-optimization-ux-conversion-guide)、[小米 HyperOS 适配](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2228)。

### 1.9 C 端 11 条陷阱（病症→后果→做法，节选自调研，已与本项目实测对齐）
1. 过期“领先”/乐观客户端状态 → 信任崩塌、退款、流失 → 只渲染服务端确认，失败兜底“状态确认中”。
2. 让买家自己算下一口价 → 犹豫、误拍 → 按钮上印“下一口价 ¥X”。
3. 一键出价无防误触 → 误拍纠纷 → 滑动/长按确认、大额 Max Bid 默认开。
4. 延时无解释 → “是不是做局” → 标注原因 + 暴露固定周期。
5. 托儿/自抬无威慑 → 珠宝直播头号信任投诉 → 明示禁托、监控、禁卖家自拍。
6. 假证书/处理货当天然 → 央视曝光、巨额罚款 → 可核验证书 + 法定命名 + 终身复检。
7. 美颜灯光失真 → 货不对板退货 → 限制滤镜、出示实拍/复检、披露色差风险。
8. 引流私下交易 → 无单据无法维权 → 出价/支付/记录全留站内并警示。
9. 退货法律口径错 → 头号纠纷 → 明示竞拍→7 天无理由适用；真拍卖→显著标表不适用 + 资质。
10. 无“你出价你就买”清晰度 → 中拍不付 → 前置说明 + 保证金 + 限时支付/罚没。
11. 直播外壳拥挤 → 失去沉浸、漏掉 CTA → 半屏/抽屉、吸底出价栏、禁堆叠半屏。

## 二、B 端：商家直播竞拍中控台

### 2.1 行业格局（谁怎么做）
| 平台/系统 | 形态 | 关键事实 |
|---|---|---|
| 抖店 Doudian | 商品/拍卖店发布、订单 | 支持独立“拍卖店”；竞价设起拍价、方式、开始时间、时长、规则 |
| 巨量百应 Buyin | PC“直播中控台” | 直播中增删改/**调序**/讲解；把商品设**“讲解中”**突出；配**数据大屏** |
| 抖音电商罗盘 | 经营数据看板 | **数据归看板、操作归中控**（分离原则） |
| eBay Seller Hub | 卖家总控 | 列表态明确分 **drafts/scheduled/active/unsold/ended**，已售归 Orders，每筛选项带计数 |
| Whatnot | 桌面 Hub + App | **桌面做生意、App 负责拍摄**；开播中 Auction 页选品→Start Auction→设参数；**最高价者赢、无人出价不成交可重拍、开拍后不可取消**；有 **Rehearsal 排练** |

**两条贯穿原则**：① **管理台 vs 开播台分离**（诊断/监控指标必须从开播台剥离）；② 拍卖参数是**一套固定字段**（起拍价/加价/封顶/时长/延时/保证金）。
来源：[抖店入驻](https://fxg.jinritemai.com/h5/enter)、[巨量百应](https://www.zhihu.com/tardis/landing/m/360/qus/400374558)、[eBay Seller Hub](https://www.ebay.com/sellerhub)、[Whatnot 开拍](https://help.whatnot.com/hc/en-us/articles/9779931101837-Start-an-auction-during-a-show)。

### 2.2 发布表单最佳实践
- **单列、从上到下**最高效（Ant Design 引 UXMatters）。
- **按字段数决定分组**（Ant 阈值）：<7 不分组；7–15 卡片/区域分组；>15 页签或分步。拍品发布建议四组：**拍品信息 / 竞价规则 / 场次与时间 / 履约**。
- **必填最小化 + 智能默认**（加价默认值、时长默认、延时默认）；组件别错配（互斥用 Radio、开关用 Switch、起止时间用单一范围组件）。
- **失焦（blur）校验，不要逐键打断**（Arco Form `validateTrigger`）。
- **金额用 InputNumber + `¥` 前缀 + 千分位**；校验“加价>0”“封顶≥起拍”。
- **延时/骤死给人话解释**而非裸参数名（照 Whatnot 口径）；**时间统一 24 小时制**。
- **图片上传**：明确大小/格式限制 + 进度提示；主图比例提示（抖店有 3:4 规则）。**支持存草稿**（eBay 把 draft 当一等状态）。
来源：[Ant Design 表单页](https://ant.design/docs/spec/research-form-cn)、[Ant 数据录入](https://ant.design/docs/spec/data-entry-cn)、[Arco 表单](https://arco.design/react/components/form)、[Arco 样式指南](https://arco.design/docs/spec/style-guideline)、[饿了么后台表单](https://www.uxbaike.com/post/20187/20717)。

### 2.3 中控台布局（如何不杂乱）
- **三栏“驾驶舱”**：左=可调序队列；中=当前拍品/当前价/出价数/在线/倒计时（大字号）；右=控制 + 互动。**首屏模块 5–9 个**（Ant 工作台）。
- **按钮主/次/危险分层（最硬规范）**：一个按钮区**最多一个主按钮**；次要操作**收进溢出菜单**；危险操作红色 + 二次确认 + **后果文案**。→「**开始拍卖**=唯一主按钮」「讲解/上一件/下一件=次按钮」「结束本场=危险」。纯图标必带 Tooltip。
- **不可逆操作二次确认**（Whatnot：开拍后不可取消）；确认弹窗用 `删除/取消` 而非 `确定/取消`。
来源：[Ant 工作台](https://ant.design/docs/spec/research-workbench-cn)、[Ant 按钮](https://ant.design/docs/spec/buttons-cn)、[Ant 可视化页](https://ant.design/docs/spec/visualization-page-cn)、[Arco 样式指南](https://arco.design/docs/spec/style-guideline)。

### 2.4 状态机 + 颜色标签
标准生命周期（对齐 eBay+Whatnot）：**草稿→待开拍→进行中→延时中→已成交 / 流拍 / 已取消**。Arco Tag 预设色映射：草稿=gray、待开拍=arcoblue(#165DFF)、进行中=green、延时中=orange/gold、已成交=green、流拍=gray、已取消=red。**状态=人话+颜色，绝不显示内部枚举名（如 STATE_LIVE/terminal）**（Semi 范例：`status→{color,中文}`）。
来源：[eBay Seller Hub](https://www.ebay.com/sellerhub)、[Whatnot 开拍](https://help.whatnot.com/hc/en-us/articles/9779931101837-Start-an-auction-during-a-show)、[Arco 样式指南](https://arco.design/docs/spec/style-guideline)、[Semi Table](https://semi.design/zh-CN/show/table)。

### 2.5 订单/记录表（脱敏、不露 UUID）
- **文本左对齐、数值右对齐、表头不居中**（Polaris）；**金额右对齐、单位进表头、千分位、全表小数位一致**（Ant 数据格式 / Polaris）；空值用 **`-`**。
- **人类可读单号（如 `#1020` / `AU20260607-000123`），绝不显示原始 UUID**；技术 ID 进**详情抽屉 + 复制**；长串截断 + Tooltip。
- **买家信息脱敏**（手机号前 3 后 4、姓名留首尾等，Ant 给了完整规则表）。
- 行内操作用文字按钮，多于 2–3 个收进“更多”；**>50 条分页**。
来源：[Polaris Data table](https://polaris-react.shopify.com/components/tables/data-table)、[Polaris Index table](https://polaris-react.shopify.com/components/tables/index-table)、[Ant 数据格式](https://ant.design/docs/spec/data-format-cn)、[Ant 数据展示](https://ant.design/docs/spec/data-display-cn)、[Youzan 数据格式](https://design.youzan.com/strategy/data-formats.html)。

### 3.2 字体与“等宽数字”（拍卖最重要的排版规则）
- C 端字体栈：`"Alibaba PuHuiTi 3.0", -apple-system, "PingFang SC", "Source Han Sans SC", "Microsoft YaHei", sans-serif`；B 端优先系统字。
- **价格/倒计时/出价数一律 `font-variant-numeric: tabular-nums`（OpenType tnum），数字不跳动 = “工程可信”**；专用数字字体可用 **Roboto Mono（Apache-2.0）**（M3 明确推荐等宽便于纵向对齐）。
```css
.price,.countdown,.bid-amount,.stat-num{font-variant-numeric:tabular-nums;font-feature-settings:"tnum" 1;}
```
- 类型阶（C 端）：展示 32/标题 24/商品名 20/正文 16/默认 14/辅助 12；CJK 正文行高 1.5–1.6，标题 1.3。

### 3.3 动效（M3 缓动 + 时长，逐交互给值）
```css
:root{
  --ease-emphasized:cubic-bezier(0.2,0,0,1);
  --ease-emphasized-decelerate:cubic-bezier(0.05,0.7,0.1,1); /* 进入 */
  --ease-emphasized-accelerate:cubic-bezier(0.3,0,0.8,0.15); /* 退出 */
  --ease-standard:cubic-bezier(0.2,0,0,1);
}
```
| 交互 | 时长 | 缓动 |
|---|---|---|
| 出价确认脉冲 | 150–200ms | standard |
| 价格跳字 | 200–250ms | standard-decelerate（配 tabular-nums 不重排）|
| 被超越告警（抖动+闪红）| 进 300 / 出 200ms | emphasized-decel/accel，闪 #FF4D4F |
| 末 10 秒倒计时脉冲 | 1000ms 循环 1→1.08→1 | ease-in-out |
| 半屏滑出 | 进 300 / 出 250ms | emphasized-decel/accel |
| 落槌/SOLD 仪式 | 500–600ms | emphasized（唯一值得花 500ms+ 的地方）|

**必做无障碍**：`@media (prefers-reduced-motion: reduce)` 关停脉冲/抖动/仪式；动效/声效必须同时有**文字+颜色**态（Apple HIG：勿仅靠动效传达信息）。
来源：[M3 缓动与时长](https://m3.material.io/styles/motion/easing-and-duration/tokens-specs)、[NN/g 动效时长](https://www.nngroup.com/articles/animation-duration)、[Apple HIG 无障碍](https://developer.apple.com/design/human-interface-guidelines/accessibility)。

### 3.4 声效（含浏览器自动播放现实）
- **现实**：浏览器**静音可自动播放、带声需用户手势后**才允许；`AudioContext` 初始 suspended，须在**用户手势里 resume()**。→ **默认静音、显式“🔊 开启声音”一键 opt-in**，在该 tap 里创建/resume Context 并预解码音源。
- 事件与规格：出价（清脆币声 0.1–0.3s）/被超越（略低提示 0.3–0.5s）/末段滴答（0.1s，1 次/秒）/落槌（木槌+短 fanfare 0.5–1.5s，最响但归一化）；单条 UI 音 ≤~1s，不循环，永远可静音并记忆选择。
来源：[Chrome 自动播放](https://developer.chrome.com/blog/autoplay)、[MDN 自动播放](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。

### 3.6 “高级且可信”Do/Don't（节选）
- **Do**：让商品摄影当主角（近黑背景衬托金玉）；金/香槟只给价值信号；处处用 tabular-nums；出价 CTA 唯一且醒目（#FE2C55）；只在落槌花一次真动效；展示溯源信任 chrome（鉴定/保证金/在看人数/服务端权威价）；尊重 reduced-motion；声音默认关一键开。
- **Don't**：满屏饱和红（CTA 红与告警红分开）；用青色 #25F4EE 做正文（对比不达标）；自动播声/循环音效；价格用比例数字（跳动毁信任）；每次出价都撒花；用带奢侈品 logo/可识别人脸的图；选没有 tnum 字形的字体；硬编码色值（用语义 token）。
