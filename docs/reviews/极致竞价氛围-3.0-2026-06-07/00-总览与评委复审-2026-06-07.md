## 0. 一句话结论（先读这一页）

**这个项目的「极致竞价氛围」加分项，不是没做后端，也不是没做 AI——而是把一套已经接近冠军的「真实信号 + AI 数据层」，用『最后一公里的呈现』把它演成了平平无奇。**

- 后端：引擎/WAL/fence/对账是冠军级（沿用既有结论）。
- **数据层（本次新发现）**：AI 与氛围的数据底座**远比任何旧文档假设的完整**——`ai_generation_jobs` 已定义 `listing_draft / auction_commentary / sentinel_explanation / auction_recap / product_qa` 五类（即旧文档 B1–B5 全在）、`auction_system_messages`（SYSTEM_AI/TEMPLATE/HOST，body≤80，带 `facts_json/safety_json/source_seq`）、`auction_risk_alerts`（防托哨兵）、commentary **异步 worker 队列**、以及**支持多模态**的 `ChatCompletionsGenerator`（`isProviderImageURL/DataURL`）。证据：`backend/migrations/202606060001_ai_atmosphere_capabilities.sql`、`202606060007_ai_commentary_worker_queue.sql`、`backend/internal/ai/chat_provider.go`、`repository.go`。
- **呈现层（失分点）**：真实信号与 AI 解说**就在手里**，却被画成——一条 6.2s 飘过的玻璃药丸弹幕（`system-barrage`，`styles.css:358-403`）、一个 1.7s 居中淡入淡出的小 toast（`atmosphere-cue`，`styles.css:666-727`）、一块**藏在「悬浮卡→出价半屏→出价榜 Tab」三层之下**的排行榜（实测 `live-stage` 内 `leaderboard` 节点数 = 0）、以及一个默认跑在**模板兜底模式**（`AI_PROVIDER_MODE=auto` 无 `API_KEY` 即用 `BuildCommentary` 确定性模板，`repository.go:261,277`）的「助手」。

> **所以本方案不是「再堆功能」。** 2026-06-07 审计明确喊停「不要再加新功能」是对的——针对的是脱节玩具（福袋/PK 当孤立摆设）。本方案做的是相反的事：**把唯一被单列计分的那条线（💫 极致竞价氛围）做深做透到极致**，且**全部复用已存在的真实信号与 AI 数据层**，只重建「呈现 + 激活」这最后一公里。

**用户的两个直觉，代码层面完全成立，且正是最高 ROI 的两刀：**
1. 「把排行榜放到外面、固定常驻、实时更新」——**对**。现状排行榜有一流的 FLIP 动画（`components.tsx:1199-1258`），却被埋在三层交互之下，直播主舞台**零竞争感**。→ 见 `02-常驻竞速榜.md`。
2. 「出价不只是一条弹幕飘过，要像瀑布一样落下来」——**对**。现状每笔出价 = 一条飘屏 + 一个小 toast，**快速连拍时是『一串弹窗』而非『越来越燃的场』**。→ 见 `03-出价瀑布与三态峰值.md`。

## 2. 五条设计原则（整个 3.0 的脊柱）

所有功能都从这五条推导，任何一条功能若违背原则即否决：

1. **真实信号驱动（Real-Signal Hype）**：每一个像素/声音/震动/AI 字，都是某个**引擎权威事件**（`engine_seq`/`decision_basis`/`facts_json`）的纯函数。**绝不**伪造在线数、稀缺、对手或出价。这既是正确性保证，也是**护城河**——见 §3。
2. **分层氛围栈（Atmosphere Stack）**：`信号层(引擎事件) → 氛围 reducer(事件→cue/强度) → 五个渲染层(持续场/事件脉冲/峰值仪式/AI 解说/触觉音频)`。每层独立降级（reduced-motion / 低端机 / AI-off / 断连恢复）。见 `01-氛围栈与情绪曲线.md`。
3. **情绪曲线（Emotion Curve）**：把一件拍品的生命周期映射成被设计过的情绪弧——`暖场 → 对抗升温 → 末段窒息 → 落槌高潮 → 余韵/钩子`，每个 beat 有明确「主控件」。
4. **三态强反馈做成「时刻」**：领先/被超越/落槌从「通知」升级为多感官的**全场时刻**。
5. **反暗黑即设计（Anti-dark-pattern by construction）**：显式列出我们**拒绝**做的事（竞品的原罪），把「氛围」从合规风险变成**成熟度加分**。见 `05`。

## 3. 护城河：为什么是「真」的氛围（你比别人强在哪）

这是面对「别人也做了类似的」时，最强的一句答辩：

> **竞品制造氛围的手段，恰恰是它们最常被点名造假的地方；我们用同样的肾上腺素，跑在『可证明为真、fail-closed』的数据上。**

- 微拍堂/珠宝直播的「捡漏」被新华网/新京报查实为**摆拍/虚假参考价**；抖音中控被央视/法治日报查实**伪造「350 人没抢到」/随机库存**；福袋中签概率低至 **0.0035%**（上观新闻），App Store 直接标「模拟赌博」；Whatnot 被 Guardian 批**隐藏累计消费、gambling-style**，App Store 现「shill bidding」差评；DealDash 的 pay-per-bid 被定性赌博邻近。（来源见 `references/`。）
- FTC《Bringing Dark Patterns to Light》(2022) 与 OECD 明确把**假倒计时、假「即将售罄」、假「他人正在看/已购」**列为欺骗；研究显示假紧迫长期掉 ~25–30% 信任。
- 本项目**架构上就做不出假**：价格/赢家/落槌由引擎决定；AI 的 `auction_system_messages` 受 `body≤80 + facts_json + safety_json + source_seq` 约束（`202606060001`），是**叙述者非裁判**。

**结论**：把「真张力」拍到极致 + 显式反暗黑 + 复用已有的 `auction_risk_alerts` 防托哨兵 = 对字节系评委（重治理/合规）的差异化叙事——**「有底线的极致氛围」**。
