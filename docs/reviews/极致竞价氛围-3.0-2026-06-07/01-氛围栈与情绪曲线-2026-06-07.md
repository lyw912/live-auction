# 01 · 氛围栈与情绪曲线（架构脊柱）

> 目的：把「极致氛围」从一堆动效，升级为**一套可论证、可降级、可测试的系统**。这是面对「资深前端/架构评委」拷打时的护身符——每个动效都能回答「它由哪个真实事件驱动、如何降级、性能预算多少」。

---

## 1. 氛围栈（The Atmosphere Stack）

```

│   引擎决策事件：bid_accepted / outbid / extended / sold /          │
│   reconciling …  携带 engine_seq · decision_basis · facts_json     │
│   热度信号：active_bidders_30s · accepted_bids_30s ·               │
│   price_velocity_cents_per_min（domain.ts:250-252，已渲染于热度计） │
│   AI 消息：auction_system_messages(SYSTEM_AI/TEMPLATE/HOST)        │
│   传输：WebSocket 推送（出价/状态）+ REST 兜底重拉（恢复）          │

                │  归一化：去重(cause_seq) · 优先级 · 恢复期抑制

┌─────────────────────────────────────────────────────────────────┐
│ L1 氛围 REDUCER（部分存在，需扩展）                                 │
│   normalizeAtmosphere() (atmosphere.ts:42) — 已做去重/优先级/单调id │

│   ➕ 新增：Gating(门控) — recovering/stale/disconnected/           │
│      reduced-motion/low-power/ai-off 的统一闸门                     │
└───────────────┬───────────────────────────────────────────────────┘
                │  输出：AtmosphereFrame { kind, intensity, facts, gated }
                ▼
┌──────────┬──────────┬──────────┬──────────┬──────────┬───────────┐
│ L2 持续场 │ L3 事件   │ L4 峰值   │ L5 AI 解说│ L6 触觉   │  渲染层    │
│ Ambient  │ 脉冲Pulse │ 仪式Climax│ Narration │ +音频     │           │
│ 竞速榜    │ 出价瀑布  │ 落槌高潮  │ 气氛官    │ 心跳床    │           │
│ 末段升温  │ 领先/被超 │ 战绩卡    │ 智能加价  │ 落锤/金币 │           │
│ 热度计    │ 越脉冲    │ 惜败收尾  │ 鉴品/Q&A  │ 震动渐强  │           │
└──────────┴──────────┴──────────┴──────────┴──────────┴───────────┘
   每层独立可关闭、独立性能预算、独立 reduced-motion 降级
```

**为什么这样分层（答辩要点）**：
- **可证伪**：任何一个炫效果，都能反查到 L0 的一个真实事件 + `engine_seq`。没有「装饰性假动画」。
- **可降级**：L2–L6 任一层失败/被门控，其余层仍工作；AI（L5）挂了不影响出价（L3）；动画（L2-L4）被 reduced-motion 关掉，信息（竞速榜文本）仍在。
- **不进热路径**：L1–L6 全在前端/旁路；AI worker 异步（`202606060007` 队列）。氛围**永远不会**成为出价正确性的新故障源。

## 2. 强度模型（IntensityModel）——「真实信号 → 幅度」的纯函数

这是 3.0 的核心新增：**氛围的强弱不是脚本，是真实数据的函数**。强度 `I ∈ {0,1,2,3}`：

| 输入（真实信号，来源） | I=0 静 | I=1 温 | I=2 热 | I=3 沸 |
|---|---|---|---|---|
| `accepted_bids_30s`（近 30s 真实出价数） | 0 | 1–3 | 4–9 | ≥10 |
| `price_velocity_cents_per_min`（真实涨速） | 0 | >0 | 高 | 极高 |
| 末段剩余秒数（服务端校时） | >10s | ≤10s | ≤5s | ≤3s |
| soft-close 触发（真实延时事件） | — | — | 提升一档 | — |

- **瀑布密度** = f(I)：I=1 偶尔落一片，I=3「数百人狂点」像倾盆。**密度来自真实出价流，不是定时器**。
- **末段升温幅度** = f(剩余秒数)：变色/脉冲/心跳 tempo/震动随真实倒计时连续加强。
- **解说激烈度** = f(I)：对标 ICML 2025「Excitement-Driven Commentary」——AI 语气随真实热度升温（见 `references` 心理学+AI）。

> 关键：I 全部由 L0 已有信号算出，**零新增后端**。这把旧文档「算好却看不见」的信号，变成了贯穿五层的能量旋钮。

## 3. 情绪曲线（Emotion Curve）——一件拍品的被设计弧

```
情绪
强度
 ▲
3│                                   ╱╲  落槌高潮(L4)
 │                          末段窒息 ╱  ╲ 战绩卡/落锤/礼花瀑布
2│                  对抗升温       ╱    ╲
 │        ╭─ 暖场 ─╮   瀑布+竞速榜╱      ╲___ 余韵/钩子
1│   ____╱         ╲____________╱            ╲____ 「下一件 30s 后」
 │  冷场? AI气氛官                                  惜败温柔收尾
0└──────┬────────┬──────────┬────────┬─────────┬──────────▶ 时间
      开拍     首拍/榜动    持续对抗   末10s     落槌      结算前
```

| Beat | 主控件（层） | 真实信号 | 反「冷场/平淡」手段 |
|---|---|---|---|
| 暖场（开拍, 0 出价） | AI 气氛官(L5) + 竞速榜空态(L2) | `no_bid` | AI 开场白 + 「等你第一手」呼吸态，**不伪造人气** |
| 首拍/榜动 | 出价瀑布(L3) + 竞速榜 FLIP(L2) | `bid_accepted` | 第一片瀑布 + 榜单首次点亮 + 金币音 |
| 持续对抗 | 竞速榜 + 瀑布密度(I) + 热度计 | `active_bidders_30s` | 「守塔/偷塔」差距文案 + 瀑布随真实速率变密 |
| 末段窒息（≤10s） | 末段升温(L2) + 触觉音频(L6) | 服务端剩余秒数 | 变色+脉冲+心跳 tempo+震动+「going once/二/三」 |
| soft-close 延时 | 倒计时拉伸(L2) + AI(L5) | `extended` 真实延时 | **可视化**「+10s 延时！还有人在拼」（对标 TikTok Extended UI 显示） |
| 落槌高潮 | 峰值仪式(L4) + L6 | `sold`（引擎权威） | 礼花瀑布 + 赢家聚光 + 落锤音 + **可分享战绩卡** |
| 余韵/钩子 | 战绩卡 + 竞速榜余温 | 终态 facts | 惜败「差一口 ¥X」温柔收尾 + 「下一件」钩子 |

## 4. 降级矩阵（Degradation Matrix）——评委必问「网络抖动/低端机/无障碍怎么办」

| 条件 | L2 持续场 | L3 事件脉冲 | L4 峰值 | L5 AI 解说 | L6 触觉音频 |
|---|---|---|---|---|---|
| 正常 | 全开 | 全开 | 全开 | 真 LLM 流式 | 全开（默认音关，opt-in） |
| `prefers-reduced-motion` | 文本/即时态（无动画） | 无瀑布，仅文本计数 | 静态战绩卡，无礼花 | 不变（文本） | 保留音/震动，去视觉 |
| 断连/恢复(stale) | 去饱和、冻结榜单 | **抑制脉冲**（不播假领先） | **抑制**（不播假落槌） | 暂停（避免对旧态解说） | 静音 |
| 低端机/低电量 | 全开（纯 transform） | 瀑布粒子上限↓、canvas 降帧 | 礼花粒子上限↓ | 不变 | 不变 |
| AI 关 / API 不可达 | 不变 | 不变 | 不变 | **回落 `BuildCommentary` 确定性模板**（已存在 `repository.go:261,277`） | 不变 |
| 无数据/0 出价 | 空态呼吸，不伪造 | 无 | 无 | 暖场白（标注「助手」） | 无 |

**两条铁律**：①「恢复期/stale 永不升温」——复用现有 `recovering` 抑制（`atmosphere.ts` 的 `recovering` kind + main.tsx 抑制逻辑）。② AI 任何失败都**静默回落模板**，绝不阻塞、绝不报错给买家。
