# 05 · 真实信号护城河 · 反暗黑治理

> 这是面对「别人也做了类似氛围、你强在哪」与字节系评委（重治理/合规）拷打时，最锋利的一篇。核心：**竞品制造氛围的手段，恰恰是它们最常被官方点名造假的地方；我们用同样的肾上腺素，跑在『可证明为真、fail-closed、可对账』的数据上。**

---

## 1. 竞品「氛围」的原罪清单（全带来源，见 `references/`）

| 竞品手段 | 被点名的问题 | 来源 |
|---|---|---|
| 珠宝/文玩直播「捡漏」 | **摆拍/表演、虚假参考价**（喊价 6 万 →6000「放漏」是演的） | 新华网、新京报 |
| 直播间中控「捧哏」 | **伪造「350 人没抢到」、随机库存、「秒拍秒付」假紧迫** | 央视网、新华网、法治日报 |
| 福袋/抽盒 | 中签概率低至 **0.0035%**、不透明，App Store 标「**模拟赌博**」 | 上观新闻、央广网 |
| Whatnot | **隐藏累计消费、gambling-style、易上瘾**；用户报告 **shill bidding** | The Guardian、App Store 评论 |
| DealDash | **pay-per-bid**「娱乐拍卖」，赌博邻近 | App Store |
| 假在线人数/刷量 | 杭州互联网法院判决、市场监管处罚、清退 239 万账号 | 杭州互联网法院案例 |

## 2. 本项目的「反暗黑宪章」（设计即拒绝）

把上面每一条原罪，翻译成一条**我们架构上就拒绝做**的承诺——并标注**为什么我们做得到**：

| 我们拒绝 | 为什么做得到（架构保证） |
|---|---|
| ❌ 假在线/观看人数 | 只显示**真实** `active_bidders_30s`/`accepted_bids_30s`（已渲染于热度计）；旧版写死 `2333` 已被 06-07 移除 |
| ❌ 假倒计时/刷新重置 | 倒计时**服务端校时、漂移无关锚点**；soft-close 延时是**真实引擎事件**且**上屏可见**（`03`§C.2） |
| ❌ 幻影出价/托/刷价 | 出价由引擎权威决策，**可对账**；`auction_risk_alerts` 哨兵实时打分（§3） |
| ❌ 假稀缺/假「即将售罄」 | 拍品/库存为真实状态；不造「仅剩 N 件」 |
| ❌ 赌博式抽奖/盲盒诱导 | 不引入 pay-per-bid、不引入低概率抽奖玩法 |
| ❌ AI 编造价格/赢家 | AI 受 `body≤80 + facts_json + safety_json + source_seq` 约束，**叙述者非裁判**（`04`§2） |
| ❌ 羞辱/逼单/confirmshaming | 惜败「差一口 ¥X·你已尽力」中性收尾（`03`§D.2）；加价仅「建议」 |
| ❌ 隐藏累计消费 | 出价/订单可读可查（PC 订单表已人读化） |

> 这张表本身就是一页**答辩 PPT**：把「氛围」从「会不会被质疑造假」的风险，变成「**有底线的极致氛围**」的成熟度加分。

## 3. 把「防托哨兵」做成可见的信任氛围（复用 `auction_risk_alerts`）

后端已有 `auction_risk_alerts(severity/risk_type/score/explanation/recommended_action/status)` + `sentinel_explanation` AI 任务（`migrations/202606060001`）。3.0 把它从「后台告警」升级为**可演示的信任叙事**：

- **主播/平台侧**：实时异常评分（自我抬价图、节奏异常、设备/IP 聚集、撤退模式）→ 主播告警 + 可配置**自动暂停/对账**（接现有 `异常取消`/`RECONCILING`）。`sentinel_explanation` 用 AI 生成**人读解释**（「疑似 A、B 在 12 秒内交替抬价 8 次」）。
- **买家侧（克制）**：不渲染具体风险（避免误伤/泄露），但「本场竞拍受反作弊保护」这类**信任徽标**可上屏，呼应「可核验」chip。
- **为何加分**：直击评分维度「数据采集（出价、用户行为）→ 数据治理 → 异常告警」，且与 fail-closed/对账气质天然契合。Whatnot 明确禁止/监控 shill；学术上聚合特征模型可达 ~97%（`references`）。**旁路异步、不进热路径、hybrid（规则 + ML/LLM-as-judge），先建议再确认。**

---

## 4. 弱势保护（主动写进答辩）

- 末段升温**克制**（避免诱导冲动）；可选「理性提示/冷静」诚实文案，不羞辱。
- 入场/榜一特效类玩法若引入，**必须配未成年门控**；本方案默认**不引入打赏/盲盒**等高风险玩法。
- AI 气氛官**不得对疑似未成年/异常用户施压**；safety_json 可承载此类门控。

> 「Pop Mart 的拆盒、Whatnot 的 reveal、微拍堂的落槌，给你的是**赌博式的多巴胺**；我们给你**一模一样的肾上腺素，但每一个数字都能回链到一次可对账的真实引擎决策**。别人怕评委问『这数据真吗』，我们**主动把对账入口摆上桌**。这就是为什么选我们——**极致，且有底线**。」
