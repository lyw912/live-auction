## A. 中国直播竞拍氛围（产品拆解）

**核心可抄机制**
1. **soft-close 延时（淘宝/闲鱼/阿里拍卖）**：末 5 分钟内任意出价把结束时间 +5min，无限重触发；**结束时间是服务端真实事实**。杀狙击、把末段变开放式对决、抬高成交价。本项目已有延时引擎——缺的是**把它演出来**。出价规则也server-authoritative：首拍=起拍价、领先时不能自我加价、整数倍加价幅度。
2. **微拍堂/对庄翡翠/天天鉴宝（中国最激烈的实时竞价 UX）**：直播把 24–48h 静态拍压缩成 **2–3 分钟/件（约 480x 吞吐）**，直播占 **70–80% GMV**；买家公屏打「扣1/应价」抢拍，主播口播双人对决；中拍是**3–4 人齐声鼓掌道贺**的人味仪式；冷场时主播押韵话术re-ignite。**坑**：「捡漏」премис被新华网/新京报查实为**摆拍/虚假参考价**。
3. **抖音 PK 进度条 + 飘屏 + 福袋**：PK 进度条**双方实时总量条**→末秒「偷塔/守塔」；飘屏=高价值事件横幅；福袋=停留 N 分钟解锁的倒计时抽奖（全屏中奖弹窗）。**坑**：福袋概率近零（凑停留）、中控被央视查实**伪造「350 人没抢到」/随机库存**。
4. **得物（诚实的 bid-ask 可视化）**：聚合全卖家挂单、实时最低出价、可解释排序（最低价→履约→时间）。**全部基于真实挂单**，是「我的位置&差距」的好范本。
5. **Pop Mart 抽盒机（揭晓仪式）**：摇一摇 tease、180s 选盒计时、**拆盒即时揭晓**（不等物流）= 多巴胺峰值；隐藏款 ~1/144。**坑**：一番赏/对对碰概率 0.0035%，App Store 标「模拟赌博」。
6. **动效技术栈（YY/腾讯工程实践）**：**SVGA**（矢量关键帧，中等礼物动效，文件小、稳定性优于 Lottie）；**Lottie**（简单 UI 动效，复杂场景 janks）；**VAP/YYEVA/PAG**（alpha 通道 MP4，全屏 3D 级 + **动态插入用户名/头像**，用于个性化「恭喜 X 中签」飘屏，H.265 体积/质量最优）；公屏弹幕用 Canvas/WebGL。实践：SVGA 做常规反馈，VAP/YYEVA 仅留给落槌/jackpot，**不无差别用 alpha-MP4**（逐帧重绘=持续耗电）。

## B. 全球直播竞拍基准

**核心可抄机制**
1. **Whatnot（游戏化金标准）**：swipe-the-Bid 一键出价、下一有效增量**预显**、增量随价上调；两种时钟——**Standard**（每次新出价加几秒，soft-close 续战）与 **Sudden Death（💀 标识）**硬结束；多数 ≤30s；Max/pre-bid 代理引擎；crowd 层：giveaway/raids/share meters。Bloomberg 称其为「rapid-fire auctions」工程化让人持续花钱。
2. **TikTok Shop Countdown Bidding（最佳 server-authoritative 范本）**：内置计时；**Fixed**（零点硬结束）vs **Extended**（末刻出价重置到卖家预设延时，可重复，**延时时长显示在 UI**）；可看他人出价、设 max；出价**不可撤、具约束力**；必须走此唯一功能、按卖家健康分准入——平台控制即信任。
3. **eBay / eBay Live**：硬结束 + 代理(二价)；eBay Live 末 5s+5s 软结束；正试点 extended bidding。**争议有教育意义**：狙击者称末秒出价是**反 shill 的正当防御**；延时派称匹配高端行、抬价——延时 UX **有争议、非普世「好」**。
4. **苏富比/佳士得/Fair Warning（gravitas 而非街机）**：氛围靠**仪式与人的权威**——paddle 号（身份+问责）、直播拍卖师、苏富比末分钟 +2min 软结束；拍卖师工具箱（开场 30s 立威、策略性沉默、社会证明「电话上有兴趣」、稀缺「最后机会」、**Fair Warning**=明确口头预告即将落槌，给最后机会）；「knocked down」=落槌成交。
5. **Fanatics Live（hype + 强制信任）**：卖「feel like a superstar」「the crowd is always going wild」、**reveal（开卡/揭晓）是情绪payload**；信任靠**三机位 + 镜头内分拣**（卡不离框）、重度卖家审核、同步释放时间。
6. **StockX（可视化即钩子）**：**Highest Bid vs Lowest Ask 价差订单簿** + 深度，真实双边需求、零表演。
7. **Twitch Hype Train（集体能量升级模型）**：独立参与者支持冲过阈值触发→ Hype-o-Meter 充能→5 分钟内充满升级→**计时重置、目标提高**；失败→无奖励（损失厌恶）；成功→**全员共享奖励**；**集体、封顶(L5)、时限、奖励参与**。

**hype vs trust 谱系**：街机(Whatnot/Fanatics)→市场(StockX)→gravitas(苏富比)。server-authoritative + 禁造假系统的打法：**借舞台（soft-close 戏剧、💀 标识、Fair Warning 口播、win/reveal 动画、Hype-Train 式真实聚合条、真实高价者榜），但每个数字严格取自权威态**——放大真相而非发明数字。

**坑（评委会嘲笑的）**：chandelier/shill bidding（拍卖师假装接场内出价造需求）；假/可刷新重置倒计时（>60% 买家会刷新测试）；pay-per-bid/盲 spins（赌博邻近、Guardian 批 Whatnot 藏累计消费）；主播逼单/羞辱；无软结束的末秒抢拍不公；无封顶的无限延时疲劳；事后撤回透明度（Fair Warning 停报 Artnet 结果）。

## C. 实时动画工程（60fps 移动 H5）

**结论（本项目现状=已手写 WAAPI FLIP、零动画库，是对的基线）**
1. **名次重排**：FLIP（getBoundingClientRect 前后 + `el.animate` transform）是唯一保持合成层的法子；**批量读再批量写**避免 layout thrashing；突发**每 rAF 合并重排一次**（~10Hz），中途打断从当前 rect 重测。库（framer-motion `layout` ~30–50KB、auto-animate ~3KB）非必需——**保留手写 0KB FLIP**。
2. **庆祝/瀑布**：**canvas-confetti**（~6KB、`useWorker` 跑 OffscreenCanvas/Worker **不占主线程**、`shapeFromPath` 自定义币/卡形、`disableForReducedMotion`）=「币/卡瀑布」首选；**SVGA**（gzip<18KB WebGL，**中国直播标准**）留给设计师产出的「大礼」；Lottie 移动端须 `renderer:'canvas'`；Rive 200KB WASM 仅多动画时值；alpha 视频 iOS/Android 碎片化，慎用。
3. **弹幕**：`danmaku`(canvas 引擎) live 模式自带泳道/碰撞；**DOM 适合 ≤数十条，>~100 并发须 canvas**（一次重绘胜过上百合成层）。
4. **数字滚动**：**CSS translateY 数字条**(0KB,合成层) 最划算；odometer.js ~3KB(有 reflow)；Motion `<AnimateNumber>` 2.5KB(需 Motion)。
5. **60fps 纪律**：只动 `transform/opacity`（filter blur≤10px）；**WAAPI/CSS 走合成线程，rAF JS 补间不走**→出价路径优先 `el.animate`/CSS；`will-change` 节制；`content-visibility:auto` 给离屏；`prefers-reduced-motion` + 应用内开关。
6. **触觉+音频**：Vibration API 需手势激活，**iOS 历史不可靠/Firefox 129+ 移除→特性检测、纯增强**；WebAudio 短音用 Oscillator 包络(0KB)或 audio sprite；**iOS 必须在首次手势内 `audioCtx.resume()`**，`statechange→interrupted` 再 resume，静音键会静音。

**推荐栈**：手写 WAAPI FLIP + CSS 数字条（0KB，合成层）；懒加载 canvas-confetti(`useWorker`) 做庆祝、danmaku(canvas) 做弹幕；可选 SVGA 大礼；触觉+音频纯增强 + iOS resume 解锁；全部 `prefers-reduced-motion`/特性检测降级。

## D. 竞价心理学 + AI co-host

**Part A — 竞价说服心理（证据+机制，全部可用真实信号实现）**
- **竞争唤醒/auction fever**（Ku/Malhotra/Murnighan 2005；Adam 2015 生理实测）：竞争+时间压力→唤醒→超过预算出价；**唤醒只在相信对手是真人时触发**→「surfacing 真实对手」是最高杠杆。
- **quasi-endowment**（Heyman/Ariely 2004）：领先越久越「觉得是我的」，丢失越痛；115k eBay 拍末日 +$1。
- **escalation/sunk cost**（dollar-auction 陷阱）：展示**真实**自己出价次数/投入，不做愧疚 nudge。
- **loss aversion + FOMO**（Klarna 2024：真实稀缺下 47% 更快下单）；**social proof/herding**（Wharton value meter，仅真实数字）。
- **near-miss**（Clark 2009 Neuron）：差一点激活「赢」脑区→「被反超 ¥5，再出？」用**真实差额**。
- **anti-sniping/soft-close**（Roth/Ockenfels；Houser/Wooders Yahoo 实验）：硬结束催生狙击且**降收入**；软结束消除狙击均衡、更公平、抬价——**更刺激且更可信的双赢**。Lee/Malmendier「Bidder's Curse」：**42–73% eBay 拍成交价高于同时可得的一口价**。
- **伦理线**（FTC 2022 / OECD）：假倒计时、假「即将售罄」、假「他人正在看/已购」、confirmshaming=欺骗；假紧迫长期掉 ~25–30% 信任。→ **印证 server-authoritative/禁造假是对的**：上述每条都能用真实后端信号实现。

**Part B — AI 直播 co-host（已是生产基建）**
- 数字人主播：JD **7 万+商家**用、约 1/10 成本；百度「数字人罗永浩」6h **¥55M**、反超真人；PLTFRM 30 个 avatar 24/7；硅基智能 **50 万克隆**、~5 万场/日、单数字人 >¥50万/月 GMV。**坑**：弱网延迟 >500ms、直播冲动购买退货率高。
- 交互 avatar API：HeyGen LiveAvatar(WebRTC/BYO-LLM, ~$0.10–0.25/min)、D-ID(~$0.56/min)、Akool/A2E。
- **AI 解说已被验证**：AWS+Bundesliga 多风格实时解说 **7–12s e2e**；WSC 复盘脚本 3–4h→**1–2min**；NUS/ByteDance **LiveCC**(CVPR 2025) **逐 token 实时解说**。AI 弹幕审核成熟(ms 级)。多模态商品描述/鉴别可行但 **VLM 视觉幻觉**是核心风险→须 hedge + grounding。

**心理机制实现排序（全真实信号）**：①真实对手在场+被超越 ping ②soft-close 自动延时 ③「领先 Xs」quasi-endowment 徽标 ④真实近失「差 ¥X 再出？」⑤真实倒计时 + going once/twice ⑥真实社会证明(真实人数)。
**AI co-host 排序（demo 影响 × 可行性）**：①实时 bid 解说(短输出、低成本) ②智能加价芯片(读权威价) ③冷启动暖场(标注助手) ④落槌复盘(便宜高传播) ⑤多模态 Q&A(RAG grounded、hedge) ⑥AI 审核+情绪 hype 旋钮。
**护栏**：无伪造信号；真倒计时+延时规则前置披露；无 confirmshaming；**LLM 读权威态、系统提示+输出校验禁造价格/赢家**；多模态 hedge；披露 AI；保护弱势(出价提醒)。
