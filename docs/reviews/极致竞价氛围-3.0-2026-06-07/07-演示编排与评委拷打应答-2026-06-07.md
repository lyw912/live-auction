## 1. 演示哲学
- **演情绪曲线，不演功能列表**：让评委在 90 秒内**亲历** 暖场→对抗→窒息→落槌→余韵 的完整弧。
- **左 H5（买家）/ 右 PC（主播中控）双屏**：PC 用「演示驱动」触发**真实竞争出价**（走真实引擎，非假动画），H5 实时炸裂。**所有炫效果都由真实引擎事件驱动**——这正是「真实信号 hype」的现场证明。
- **录前必做**：`p0smokeseed`（`auc_live.end_at` 会过期）；接 `API_KEY` 启真 AI；`accept.mjs` 绿；确认音频已 opt-in 解锁。

## 3. 「只有一个真人用户，会不会显得假？」

- **不假**：PC 演示驱动触发的是**真实出价**，走完整引擎判定/WAL/对账，H5 看到的是**真实事件**的氛围反应。脱敏买家名是真实账号脱敏，不是编的。
- **诚实披露**：演示时直说「为压缩时间，竞争出价由中控驱动，但每一笔都是真实引擎决策」——比假装「几百人在线」更可信，且**正中评委对真实性的偏好**。
- 对比：微拍堂/中控造假被官方查处（`05`）；我们**主动暴露驱动来源 + 对账入口**。

## 4. 评委拷打应答（Q&A 库，按攻击视角）

**【前端/性能】**
- Q：瀑布 + 礼花 + 10Hz 倒计时，移动端不卡？
  A：只动 transform/opacity；瀑布/礼花在 canvas/`useWorker`(OffscreenCanvas)；倒计时 tick 已**下沉叶子 + `React.memo`**，不再全树重渲染；粒子有上限、低端机减半、隐藏页自停；trace 门禁断言无 >50ms 长任务（`06`§3,§8）。
- Q：无障碍？A：`prefers-reduced-motion` 全层降级 + 应用内「减弱效果」开关；`aria-live` 分级；色彩不单独承载信息（`06`§5）。

**【产品/营销心理】**
- Q：这些动效有依据还是炫技？A：每个效果绑一个真实引擎事件 + `engine_seq`；强度由真实速率/秒数驱动（`01`§2）。心理学锚点：竞争唤醒、quasi-endowment、真·near-miss、soft-close（`references`），**全部用真实信号实现**。
- Q：被超越显「差 ¥50」是不是诱导？A：是**真实差额**的近失，不是编造；惜败中性收尾、加价仅建议、无 confirmshaming（`05`§2）。

**【Live-Ops/主播】**
- Q：没口才主播会冷场？A：AI 气氛官接管情绪劳动 + 暖场 + 升温解说；竞速榜/瀑布提供天然解说素材（`04`§3）。
- Q：soft-close 会不会让人觉得被套？A：延时**上屏可见**（对标 TikTok Extended UI）、规则透明、有 Sudden Death 标识区分不延时件（`03`§C.2）——透明即信任。

**【商家】**
- Q：商家凭什么用？A：`listing_draft` 一图成稿 + 建议定价（eBay 95% 采纳）；复盘给下一件建议起拍价；地位榜单是「自动逼单员」（`04`/`02`）。

**【后端/SRE/正确性】**
- Q：AI/氛围会不会拖垮出价或播假成交？A：全部旁路异步（commentary worker 队列 `202606060007`）；恢复期/stale **抑制升温**、不播假领先/成交；AI 失败**静默回落模板**；关掉 AI 出价/落槌照常（`01`§4、`04`§6）。
- Q：AI 会不会报错价格/赢家？A：受 `body≤80 + facts_json + safety_json + source_seq + UNIQUE` 约束，叙述者非裁判，系统提示+输出校验双保险（`04`§2）。
- Q：榜单实时一致？A：改 WS 增量、`cause_seq` 单调合并，顺手修了 outbid 竞态（`02`§6,§7）。

**【治理/合规】**
- Q：和那些被查处的直播间区别在哪？A：反暗黑宪章（`05`§2）逐条对应竞品原罪；无假人气/假倒计时/假稀缺/赌博玩法；防托哨兵 + 对账可演示；AI 明确标识 + 未成年门控。

**【创新性】**
- Q：AI 是不是套壳？A：不是整张数字人脸（成本/延迟/合规重）；是**轻量、可控、强约束的实时解说气氛官 + 多模态鉴品**，且**复用已建的五类 job/worker/多模态 provider**，是把真实信号数据层激活成差异化体验——比「贴个数字人」更难、更落地、更经得起追问。

## 5. Demo 失败模式与兜底
- **AI/外网抖动** → 模板兜底 + 纯文本解说降级；预生成一条「必燃」末段解说。
- **音频未解锁** → 开场先点「开启提示音」（同时解锁 AudioContext）。
- **数据过期**（`end_at` 到点）→ 重跑 `p0smokeseed`；`accept.mjs` 绿再录。
- **粒子卡顿**（低端演示机）→ 「减弱效果」开关一键降级，信息不丢。
- **绝不**临场开三窗口/扫诊断全量/用「拍卖」字样（沿用 06-07 演示纪律）。
