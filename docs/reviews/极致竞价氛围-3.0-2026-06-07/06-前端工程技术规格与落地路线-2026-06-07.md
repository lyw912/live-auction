# 06 · 前端工程技术规格与落地路线

> 给执行模型/工程师的单一落地参考。原则（与 `references` 动画工程一致）：**能 0KB 就 0KB、重库懒加载、只动 transform/opacity、事件驱动而非每 tick 重渲染、每层独立降级**。不改出价判定/结算/幂等/API 契约（仅新增 WS 增量与 AI 激活）。

---

## 1. 组件架构（H5，扩展而非重写）

```
main.tsx (App)
 ├─ WS 事件总线  ── bid_accepted / outbid / extended / sold / leaderboard_delta / system_message(SYSTEM_AI)
 │     └─ atmosphere reducer (atmosphere.ts)  ── normalize + IntensityModel + Gating  → AtmosphereFrame
 ├─ <LiveStage>
 │    ├─ <RaceBoard>          (L2 常驻竞速榜, 复用 LeaderboardRows FLIP)        ← 新增
 │    ├─ <BidWaterfall>       (L3 canvas 瀑布, rAF, 粒子上限)                   ← 新增
 │    ├─ <CohostRibbon>       (L5 AI 气氛官流式话语带 + AI 标识 + 关闭)         ← 新增
 │    ├─ <CountdownHeatLayer> (L2 末段升温曲线, countdown-phase 驱动)           ← 扩展
 │    ├─ <HeatMeter/>         (已存在, 真实热度)
 │    ├─ system-barrage       (横向系统播报, 与瀑布分工)
 │    └─ <AtmosphereCue/>     (L3 三态: 领先金扫/被超越红砸+真实差额)            ← 升级
 ├─ <AuctionStatePanel>       (出价器 + PriceOdometer + 加价芯片)               ← 扩展
 └─ <ClimaxLayer>             (L4 礼花 useWorker + 聚光 + 战绩卡, 先于支付)      ← 新增
```

**叶子化 + memo（解决 10Hz 隐患）**：100ms 倒计时 tick 只驱动 `CountdownHeatLayer` 与价格数字两个叶子组件（`React.memo`），**不再让整个 App 每秒 reconcile 10 次**（2026-06-05 §4.8 隐患）。氛围组件全部**事件驱动**（频率=出价速率/状态变化，远低于 10Hz）。

## 2. 数据契约（新增，最小侵入）

```ts
// 1) 排行榜增量（WS 房间级，每次引擎接受出价后下发；替代 5s REST 重拉）
type LeaderboardDelta = { auction_id; cause_seq; /* =engine_seq */
  top: {rank;user_masked;amount_cents;bid_count;is_current}[];  // Top-3~5
  me?: {rank;amount_cents;gap_to_leader_cents};
  heat: {accepted_bids_30s;price_velocity_cents_per_min}; };

// 2) AI 解说（已存在 auction_system_messages, source=SYSTEM_AI）
type SystemMessage = { id; source:'SYSTEM_AI'|'SYSTEM_TEMPLATE'|'HOST';
  source_seq; style; body /* ≤80 */; facts /* 引擎事实 */; safety; };

// 3) 氛围帧（前端内部, reducer 产出）
type AtmosphereFrame = { kind:'leading'|'outbid'|'extended'|'sold'|'recovering'|'social';
  intensity:0|1|2|3;  // IntensityModel(真实信号)
  facts:{ amount_cents?; gap_to_leader_cents?; seconds_left?; extend_ms? };
  gated:boolean; };   // recovering/stale/disconnected/reduced-motion/ai-off
```
- 所有帧/消息共用 `cause_seq`(=`engine_seq`) 去重排序 → **天然修复 outbid 竞态**（`02`§7）。
- `LeaderboardDelta` 需后端在出价接受后向房间广播（与现有出价/状态 WS 同通道）；`me`/`heat` 字段后端已有，仅需组帧。

## 3. 动画/性能预算

| 层 | 技术 | 体积 | 帧预算 | 降级 |
|---|---|---|---|---|
| FLIP 名次 | WAAPI(手写, 已存在) | 0 | 合成层, off-main | reduced-motion→即时重排 |
| 价格 odometer | CSS translateY 数字条(手写) | 0 | 合成层 | →即时数字 |
| 出价瀑布 | canvas + rAF(手写) | ~0 | ≤24 片同屏, 隐藏页自停 | →竞速榜计数跳动 |
| 落槌礼花 | canvas-confetti `useWorker`(懒载) | ~6KB | OffscreenCanvas/Worker, ≤180 粒子一次性 | `disableForReducedMotion` |
| 末段升温 | CSS keyframes(扩展) | 0 | 合成层, blur≤10px | →文字节拍+音/震动 |
| AI 气氛官 | 文本流式 + 可选 TTS | 0 | DOM 轻量 | →模板/关闭 |
| 触觉音频 | WebAudio 合成/小采样 + Vibration | ~0 | — | iOS 特性检测, 默认音关 opt-in |

**铁律**：只动 `transform`/`opacity`；`will-change` 仅在动画进行时加、结束移除；`content-visibility:auto` 给离屏榜单行/历史；重库 `import()` 懒加载（初始包 +0）。

## 4. iOS / WeChat webview 关键坑（来自 `references`）
- **音频**：`AudioContext` 默认 suspended → 在**首次手势**（复用现有「开启提示音」按钮）内 `resume()` + 播 1 帧静音 buffer；`statechange→interrupted`（锁屏/后台）再 `resume()`；iOS 静音键会静音 WebAudio（提示用户）。
- **震动**：`'vibrate' in navigator` 特性检测；iOS 历史不可靠、Firefox 129+ 移除 → **纯增强，绝不依赖**。
- **视频/alpha**：webview 内 alpha-MP4 可能全屏劫持 → 落槌特效**优先 canvas-confetti/SVGA**，不用 alpha 视频。
- **Lottie**（若用）强制 `renderer:'canvas'`，默认 SVG 渲染器在移动端 janks。

---

## 5. 可访问性 / 无障碍
- `prefers-reduced-motion` 全层降级（见 `01`§4 矩阵）；额外提供**应用内「减弱效果」开关**（WCAG 2.2.2，用户可能不知系统设置）。
- 三态/名次变化 `aria-live`：领先/被超越 `assertive`，名次变化 `polite`。
- 气氛官话语带对屏幕阅读器可读；TTS 与视觉解耦。
- 色彩不单独承载信息（被超越除红光外有文案 + 图标）。

## 7. 落地路线（按答辩收益/工作量）

**P0 · 最小冠军包（先做，纯前端 + 激活）**
1. `RaceBoard` 常驻竞速榜 + WS `leaderboard_delta`（顺修 outbid 竞态）。
2. `BidWaterfall` 出价瀑布 + 三态 cue 升级（金扫/红砸+真实差额）+ `PriceOdometer`。
3. `CountdownHeatLayer` 末段窒息（升温曲线 + going once/二/三 + soft-close 可视化）+ 心跳音床。
4. AI 气氛官**激活**：接 `API_KEY` + `CohostRibbon` 买家侧呈现（D-1/D-4）。
5. `ClimaxLayer` 落槌高潮 + 战绩卡（接 `auction_recap`）。
+ 倒计时 tick 叶子化 + `React.memo`（性能前置）。

**P1 · 深化**
- 多模态鉴品/Q&A（`product_qa`）+ 智能加价芯片（D-2/D-3）。
- 反暗黑面板 + 哨兵可视（`05`，复用 `auction_risk_alerts`）。
- 声音 2.0（分层 + ducking）、SVGA 大礼（设计师产出时）。

**P2 · 锦上**
- 商家复盘/下一件建议起拍价（`auction_recap` 商家侧）。
- （谨慎）暖场小件/阵营 PK——**仅在不脱离主线、且带防托/未成年门控时**。
