3. H5 user enters room.
4. H5 opens item detail.
5. Multiple users bid.
6. One bid triggers extension.
7. One bid triggers reject.

9. Winner pays mock order.
10. PC opens diagnostics and shows real events.
11. Reconnect scenario shows recovery.
