# Archived PTS CSV Inputs

These CSV files are retained for historical JMX compatibility and old report
reproduction. Current PTS-1A/PTS-1B uses:

```text
docs/perf/pts/inputs/s1-s5/s1-s5-1000-user-sessions.csv
```

The archived JMX files may still reference the basename expected by Alibaba PTS
upload. When rerunning an archived workload, upload the matching CSV manually and
label the result as historical or current-adjacent.
