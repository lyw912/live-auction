# H5 Auction Sound Assets

These WAV files are generated by `scripts/generate-h5-sound-assets.mjs` from deterministic oscillator/noise formulas. They are project-owned synthetic assets, not downloaded or licensed third-party samples.

Files:

- `heartbeat-bed.wav`: looping final-window tension bed.
- `whoosh-rank.wav`: rank/extension transition cue.
- `coin-leading.wav`: new-leading cue.
- `hammer-hit.wav`: sold/result hammer cue.
- `system-chime.wav`: AI/system message cue.
- `lucky-open.wav`: 福袋 reward reveal cue.
- `entry-badge.wav`: entry badge / participation cue.
- `pk-surge.wav`: buyer PK team switch surge cue.

Regenerate:

```bash
node scripts/generate-h5-sound-assets.mjs
```
